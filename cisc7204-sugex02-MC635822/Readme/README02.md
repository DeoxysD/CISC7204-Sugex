## 练习内容与答案要点

### 1. 元组与列表（`2.1` 与 Tuples / Lists 讲义）

- 创建元组：`A = (0, 1, 2, 3)`
- 取前两个元素：切片 `A[0:2]` 得到 `(0, 1)`（结束下标不包含）
- 列表同样可以切片：`B[0:2]` 得到 `['a', 'b']`
- 列表可变：`B[0] = "A"` 会把第一个元素改成大写
- 元组不可变，不能写 `A[0] = ...`
- `len(genres_tuple)` 求长度；`genres_tuple.index("disco")` 找第一次出现的下标
- `sorted((-5, 1, -3))` 会得到排好序的**列表** `[-5, -3, 1]`
- 列表拼接用 `+`：`[1, 'a'] + [2, 1, 'd']` 得到 `[1, 'a', 2, 1, 'd']`

### 2. 集合（`2.2` 与 Sets 讲义）

- `set(['A', 'B', 'C', 'A', 'B', 'C'])` 会去掉重复，得到 `{'A', 'B', 'C'}`
- 添加元素：`S.add('D')`
- 交集：`A & B` 或 `A.intersection(B)`，例如 `{1,2,3,4,5} & {1,3,9,12}` 得到 `{1, 3}`
- 并集：`album_set1.union(album_set2)`
- 子集：`album_set1.issubset(album_set3)`
- 列表可以有重复，集合不能：`sum([1, 2, 2, 1])` 是 `6`，`sum({1, 2, 2, 1})` 是 `3`

### 3. 字典（`2.3` 与 Dictionaries 讲义）

设 `D = {'a': 0, 'b': 1, 'c': 2}`：

- 按键取值：`D['a']` 得到 `0`
- 全部键：`D.keys()`
- 全部值：`D.values()`
- 自己建字典：键是专辑名，值是销量，例如 `{"Thriller": 65, ...}`，再用 `album_sales_dict["Thriller"]` 查销量
